## Protected rule and concrete repair

A successfully committed shift post or edit must return its ordinary success result even when its after-commit announcement transport raises. Failure of the posted-shift callback must not suppress the separately registered availability callback. An enclosing rollback must discard both business writes and announcements.

`backend/shifts/posting.py:119`, `:129`, `:215` now register the three existing callbacks with `robust=True`. Django logs callback exceptions and continues to independent callbacks. The posting/edit transaction, recipients, email context, visibility, pricing, permission checks and callback ordering remain unchanged. No retry, delivery guarantee or outbox is introduced. Within any one announcement helper, a recipient failure can still stop later recipients; that is explicitly separate below.

The regression uses `TransactionTestCase` and real HTTP endpoints, with actual outer commits rather than just callback capture. The original head ran five tests: two commit/rollback controls passed, and the three outage endpoint tests raised the injected `RuntimeError` through Django's `run_and_clear_commit_hooks`. This is a demonstrated request failure after durable work, not a hypothetical concern. The three failures were posting outreach, availability matching and edit outreach. Baseline execution: 5 tests, 3 errors, 0 failures, 0 skips, 0.684 seconds after real migration setup.

## Architecture decisions following the inventory

- **Billing:** no further extraction in this batch. `billing/checkout_urls.py` and four helpers in `billing/subscriptions.py` already establish coherent owners. The canonical billing evidence explicitly leaves metadata construction and provider matching in views; the earlier handover's broader eight-helper description is superseded by the narrowed final source. The module-size ratchet has no exceptions. Moving webhook/provider code only to reduce file length would increase review scope without repairing this batch's invariant.
- **Cycles:** the existing scanner observes 97 module-level edges, 72 delayed edges and seven approved mutual pairs, with the same existing larger SCC. `python3 scripts/module_import_graph.py --check --check-baseline` passed. No cycle reduction arises from adding robust callback flags; no generic shared module was introduced.
- **Stage J:** retain separate interval implementations for this candidate. `pricing._split_day_window_into_segments` partitions supplied day windows and quantizes hours to four decimals, with date-effective cut points. `engagement._award_floor_for_occurrence` interleaves splitting with changing holiday/day classification, schedule rate lookup, early overtime exits and payroll-review metadata. A shared cursor/cut-point wrapper would need caller policy callbacks or precomputed boundaries and would remove little duplication. No pricing/time function, rate data or 600-case fingerprint changed; no new pricing-equivalence claim is made.
