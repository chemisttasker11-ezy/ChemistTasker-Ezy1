Known traps (from W2's review rounds; avoid them up front):
1. Every entry point uses web's capability or workspace guards; allowed users keep access.
2. Data keyed by the current scope/workspace; a late response for an old scope never shows or acts.
3. Only the latest request writes state (request generation); 403 paths too.
4. A failed list shows retry, never "nothing to do" / zero.
5. Empty arrays keep identity (functional setters) so memoised fetchers don't re-run.
6. Precedence/branching logic lives in pure functions with tests that fail on a swap.
7. Backend links (/dashboard/...) map to existing mobile routes for the persona; delegated admins stay in /admin.
